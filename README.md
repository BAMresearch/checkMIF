# checkMIF

checkMIF reviews mechanochemical reaction records in MIF format. It highlights missing information, inconsistent values, and details that may need clarification, using A–D alerts and Info notes.

Open `index.html` in a browser and select one `.mif` file. You can export the report as JSON or text, or print it as a PDF.

The file is checked in your browser and is not uploaded by checkMIF. Results are advisory; they do not verify chemical identity, experimental safety, or publication readiness.

This is a static site. `index.html`, `app.js`, `styles.css`, and the image files can be hosted together without a build step.
